NUMBER FRIENDS — Learn & Play
================================
A number-learning app for kids 4+, built entirely from the attached
"Numbers" flashcard photos (the complete set, numbers 1–30, plus bonus
posters for 31–40 and 41–50).

HOW TO OPEN
-----------
1. Unzip this folder if you haven't already.
2. Double-click "index.html" — it will open in your web browser
   (Chrome, Edge, or Safari work best for the speech feature).
3. No installation or internet connection is required to view the
   flashcards, but an internet connection is needed the first time
   to load the "Baloo 2" heading font (it falls back to Comic Sans
   automatically if offline).

WHAT'S INSIDE
-------------
- index.html        The app itself
- css/style.css      All styling
- js/data.js         Flashcard data (number, word, sentence, image file)
- js/app.js          App logic (tabs, learn mode, quiz, rewards)
- js/confetti.js     Canvas-based confetti celebration effect
- js/speech.js       Text-to-speech helper (uses the browser's built-in voice)
- images/            The 30 flashcard photos + 2 bonus posters (31–40, 41–50),
                      resized/compressed from the originals you provided

FEATURES
--------
- Learn Numbers: flip through flashcards 1–30 with a pop-in animation,
  a "Hear the Number" button, and a "Read Entire Sentence" button that
  reads a full descriptive sentence aloud.
- Practice & Play: an 8-round "listen and tap" quiz. Correct answers
  trigger instant confetti + a star reward.
- Numbers 31–50: bonus posters with a button that reads the whole
  number range aloud in order.
- Stars counter in the header tracks progress and is saved in the
  browser automatically so kids can pick up where they left off.

NOTES
-----
- No new emojis, icons, or artwork were added — every picture on
  screen comes directly from your original flashcard photos. All
  spoken audio is generated live by the browser's text-to-speech
  engine (no external audio files).
